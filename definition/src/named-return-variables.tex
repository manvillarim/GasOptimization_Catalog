\noindent \textbf{where} $f$ and $v$ are identifiers, $T$ is a type, $P$ is a
Solidity command, $\mathit{parameters}$ is a list of identifiers, and
$[\ldots]$ denotes Solidity constructs;

\noindent \textbf{provided} $v$ is assigned on every execution path of $P$ that
reaches the end of the body, and $P$ contains no \texttt{return} statement other
than the final one.

\caption{Use named return variables.}
\label{rule:named-returns}
